# System Analyst Portfolio — обновлённая сборка

1. Распакуйте архив.
2. Загрузите `index.html` и папку `assets/` в корень репозитория `systemanalyst`.
3. Подтвердите замену существующего `index.html` (если он есть).
4. В настройках GitHub Pages оставьте текущий источник публикации.

Структура:
- index.html — сайт; исходный JavaScript интерактивных демо сохранён без изменений.
- assets/avatar.png — игровой аватар в HUD и профиле.
- assets/bpmn-guide.png — иллюстрация BPMN.
- assets/kafka-working.png — иллюстрация Kafka.
- assets/rest-thinking.png — иллюстрация REST/API.
- assets/uml-presenting.png — иллюстрация UML Sequence.

Пути к изображениям относительные, поэтому сборка подходит для GitHub Pages в подпапке `/systemanalyst/`.
